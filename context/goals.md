# Goals

- Pass the Infinity Games "Vibe Coder" assessment: a playable, great-looking
  browser prototype at a public link, built with AI tools inside the 4-hour window.
- Deliver everything in one email: the live link, a ~3 minute walkthrough video
  (with the inspiration game and a scale-or-kill verdict), the complete and
  unedited prompt log from every AI tool (including rules files), and short
  written answers.
- Show the judgment of a prototype team: pick a mechanic worth testing, prove the
  core loop fast, decide honestly whether it deserves more resources.
