# Handwritten notes (2026-11-04)

The three photos are the owner's original notes. Summary:

**Page 1 — screen flow:** game icon + simple name + easy URL → splash screen with
the emblem → loading screen with music, animation, a progress bar with haptics
that keeps creeping so it never looks frozen → main menu (title XOR logo, a big
PLAY button, at most 2 other actions, 3 small icon buttons at the bottom) →
tutorial level.

**Page 2 — tutorial rules:** immediate access back to the menu, no bloat, zero
text (symbols only), teach movement gestures first, give the player something to
own and something to be responsible for, a reward based on performance; they
don't need to learn everything, just enough to start. The empty box under the
tutorial is the core loop, decided by the brief.

**Page 3 — the flow:**
- *Start:* context, receive the email, decompile it into a `.md`, list
  deliverables, make a timeline, set targets.
- *Setup:* find a skill, an integration and a library for each deliverable.
- *Plan:* show different designs in Figma; different designs per page.
- *Grind:* step-by-step plan, one page at a time, bare-bones pages first.
- *Test:* no bugs, core loop works, deploy and connect.
- *Polish:* remove AI fluff, play the game, add haptics and music.
- *Retention:* keep user data, customisable items, grindable items, levels and
  rewards.
