Infinity Loop
        
        Game launches instantly, 
        a second after you click it from your home screen you are already presented with the menu, 
        the ui is neat (it contains an infinity loop symbol on the top part of the screen, there is no text on the game logo)
        the game has 3 modes, infinity loop, dark mode and playground
        they offer hints through video ads
        an example of a hint i got aftr watching an ad (30 second ad is too long for a single hint i think)
        they should've given me a few free hints before showing me an ad for the first hint but because i didnt know the value of a hint, i didnt know whwether it was worrth my time
        so the first ad experince wasnt great, this might be something that loses people. i say collect data to test this hypothesis
        the target state of the game isnt obvious as levels get more complex
        what a hint entails isnt obvious even after receiving it, when the hint is provided some animations should have been included to show the ai playing part of the solution instead of just jumping states
        a hint here isnt actually a hint, its the game making automatic moves to get you closer to your end goal
        i love that once a level is completed though theres a satisfying animations
        complexity is added to the game by requiring extra moves for each new puzzle rather than an improvement in strategy
        the end goal still isnt obvious so i dont know whether this is meant to be part of the complexity

        things id change: 
            
            make the end goal obvious, or at least put it up as a monetisable option
            add animations to the hints
            allow skipping a level but keep a collection group with a reward
            make each collection group be in relation to a set of symbols, greek symbols, egyptian symbols etcy
