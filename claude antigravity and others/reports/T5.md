## Implementation details
1. **Config (`public/src/config.js`)**:
   - Replaced old distance/pace chaser configuration with `CONFIG.chaser = Object.freeze({ steps: 3 })`.
   - Removed `startGapM`, `maxGapM`, `paceStart`, `pacePerSec`, `paceMax`, `chain.stepBackPerStepM`, `chain.maxStepBackM`, and `tutorial.stormDropShare`.
2. **Engine (`public/src/engine.js`)**:
   - Replaced `state.gap` with `state.chaserStep: 0`.
   - Removed `chaserPace(config, timeMs)`.
   - Implemented discrete 3-step chaser:
     - On mistake (`break` event on 1–2 chain or barrier hit `stumble { cause: 'hit' }`): outside of tutorial, increments `chaserStep += 1` and emits `{ type: 'chaser', step, dir: 1 }`. Upon reaching `steps` (3), sets `over = true, cause = 'caught'` and emits `caught`.
     - Cashing 3–5 chains has no effect on `chaserStep`.
     - 6-combo (`match` with `max: true`): if `chaserStep > 0`, decrements `chaserStep -= 1` and emits `{ type: 'chaser', step, dir: -1 }`. If `chaserStep === 0`, no-op (no banked shields).
     - Stumble duration/slowdown remains purely for game feel, without time-based creep on the chaser.
     - Updated `summary(state)` to return `chaserStep` instead of `gap`.
     - Tutorial handling: mistakes during tutorial do not advance `chaserStep`. During `tutorial.step === 'storm'`, sets `chaserStep = 1`. Upon completing storm and emitting `tutorial` `done`, resets `chaserStep = 0`.
3. **Tests**:
   - Added `tests/chaser.test.mjs` verifying all 6 required behaviors (initial 0, 3-mistake caught sequence with chaser events, cashed 3-5 chain neutral, 6-combo recovery and step 0 non-banking, quiet idle runner surviving 60s, tutorial immunity/storm step, determinism).
   - Updated `tests/engine.test.mjs`, `tests/tutorial.test.mjs`, and `tests/jump.test.mjs` to reflect discrete `chaserStep` rules.
