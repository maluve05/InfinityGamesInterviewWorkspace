## Contract (Claude's view code will rely on exactly this)
- `createGame(config, seed, { tutorial: true })` sets `state.tutorial = { step, targetLane, done }`. Without the option, `state.tutorial = null` and nothing changes.
- Steps, in order: `'lanes' → 'chain' → 'jump' → 'storm' → 'done'`. Each change emits `{ type: 'tutorial', step }`. `state.tutorial.targetLane` is the lane (0–2) the player should go to next, or `null`. The view draws an arrow or hand there.
- Rules while `state.tutorial` is set and not done:
  - Speed stays at `speed.base`. The chaser doesn't move (gap stays at `maxGapM`). A 1–2 chain break gives no stumble.
  - Normal track generation is off. The engine writes authored rows instead:
    - **lanes**: a single gem two lanes away, then one back. The step advances once the player has changed lane twice and collected one gem.
    - **chain**: three gems of one colour in a short zig-zag (each one lane apart), every other lane empty. Advances on the first `match` event. If the player misses, the same pattern comes again.
    - **jump**: one barrier in the runner's current lane, gems after it. Advances on the first `vault`. If the player hits it, it comes again.
    - **storm**: no new rows for about 2.5 s. The gap drops from `maxGapM` to about 70% of it, so the storm rises into view. Then the step goes to `done`.
  - On `done`: `state.tutorial.done = true`, normal generation and the speed ramp start from there (timeMs for the speed ramp counts from the hand-over), and the chaser starts moving.
- `CONFIG.tutorial` holds every number (row spacing, storm drop, pause length).
- Save data: add `tutorialDone: false` to the defaults in `storage.js`. VERSION stays 1. Old saves without the field load as `false`.
- main.js: `startRun` passes `{ tutorial: !save.tutorialDone }`. When a `tutorial` event with `step: 'done'` arrives, save `tutorialDone: true`. Nothing else in main.js.

## Tests (tests/tutorial.test.mjs, plus storage tests)
- No option → `state.tutorial === null` and the existing tests still pass.
- A scripted player who follows `targetLane` and jumps the barrier gets through all 5 steps in order, with events in order, in under 40 s of game time.
- A player who never moves stays on `'lanes'` or `'chain'`, is never caught, and the gap never drops below `maxGapM` during those steps.
- Hitting the tutorial barrier repeats the `jump` step and doesn't count as a stumble toward being caught.
- After `done`, the generated track follows the normal rules (thread, colour unlocks, the T3 barrier spacing).
- Storage: defaults include `tutorialDone: false`. An old save without the field loads `false`. Save/load round-trips `true`.
